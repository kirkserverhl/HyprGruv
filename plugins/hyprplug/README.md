# hyprplug

HyprGruv’s hyprbars-only plugin repo for `hyprpm`.

Vendored from [hyprwm/hyprland-plugins](https://github.com/hyprwm/hyprland-plugins) at the
tag matching the targeted Hyprland stable (currently **v0.56.0** for Hyprland **0.56.x**).

See [UPSTREAM.md](UPSTREAM.md).

Registered by `lib/scripts/hyprpm.sh` from this tree (local git), so HyprGruv stays
buildable offline and does not depend on a separate GitHub push.
